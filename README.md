# Albion Fan Hub

## UX/UI Developer Case Study

An unofficial, self-directed UX/UI case study exploring how a modern football club could improve the digital matchday experience for supporters.

This project is being developed as part of my application for a Junior UX & UI Developer role.

## Project Goal

The aim is to explore how user journey mapping, UX principles and front-end development can be combined to create a simple, accessible and personalised digital experience for football supporters.

## Current Focus

- User journey mapping
- UX research and problem definition
- UI design and prototyping
- Responsive web design
- React
- TypeScript
- Accessibility
- Personalisation
- AI-assisted development
